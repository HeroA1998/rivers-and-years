# 高清武俠書卷風 UI — 素材與驗收記錄

此分支只改 HTML/CSS/介面模板。不修改 `js/game.js`、`js/events.js`、`js/chronicle.js`、`js/adventure.js`、`js/chains.js`、`js/die3d.js`，也不更改 `SAVE_KEY`。

## 美術方向

- 宋代/傳統武俠氛圍，深墨、暖宣紙、玉綠、朱砂、古銅金；高清而非像素化。
- 人物要求寫實與精緻插畫的折衷：自然五官、非 Q 版、成人寫實比例、符合古風服飾。
- 事件圖片、人物立繪維持原始比例，不以 `image-rendering:pixelated` 放大。
- 頂欄收合能力值、保留生命與內力；江湖主頁保留「歷練」作唯一主行動。
- 事件的三選項與禁用狀態、等級配點、武功裝備、買賣、戰鬥、3D 骰子不修改實際行為。
