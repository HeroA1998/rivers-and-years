# 江湖歲月錄

以文字為主、水墨場景圖為輔的武俠人生模擬遊戲。純 HTML/CSS/JS，無需建置，手機瀏覽器直接開 `index.html` 即可遊玩（存檔在瀏覽器本機）。

- **主線故事**：每局隨機生成。爭奪之物、背後真相、幕後黑手、內奸、三位守護者的所在各自隨機（共 81 種組合，再配上不同地點），由玩家行動推進；「江湖」頁上方顯示當前目標。內容在 `js/story.js`。
- **奇緣**：隨機觸發的多段小故事（託孤、古寺夜哭、鏢銀失竊、三碗酒），每條的內情每局不同。內容在 `js/chains.js`。
- **手機版面**：以 410 單位寬為基準整體等比放大，戰鬥一屏內完成。
- **時間**：天啟元年正月初一起，每個行動消耗天數，年月日與四季遞進；元宵、七夕、九月初九英雄會等節日定期觸發。
- **事件**：奇遇、戰鬥、戀愛、傳承、江湖五類，依地點、季節、屬性、聲望等條件隨機觸發；另有「天機圖」主線（三、五、七年）。
- **武功**：內功／劍法／刀法／拳掌／暗器／輕功六系，陽剛・陰柔・中和三屬性，入門・上乘・絕學三階，每門十層。
- **戰鬥**：猜拳式對決。每回合雙方各排六手，攻克破、破克守、守克攻；敵人各有慣用套路，交手越多、悟性越高，能預先看穿的手數越多。絕招耗內力、無視克制。
- **門派**：天嵐劍宗、般若寺、玄真觀、百花谷、血煞教、風塵幫，各有入門條件、職位晉升與鎮派絕學。
- **傳承**：高人傳功、掌門衣缽、收徒、生子；歸隱後可選一門武功傳給下一代繼續遊玩。

檔案：`js/data.js` 資料、`js/events.js` 事件、`js/game.js` 引擎、`js/ui.js` 介面、`js/art.js` 備用的程式繪製場景。

場景圖在 `assets/art/`，取自克里夫蘭美術館開放典藏的中國古畫（CC0），出處見 `CREDITS.md`。
