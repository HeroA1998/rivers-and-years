# 江湖歲月錄・金庸編年史

以文字為主、古畫與立繪為輔的武俠人生模擬遊戲，背景是金庸《射鵰》《神鵰》《倚天》三部曲的年代。你不是書中的主角，而是那個年代裡的一個江湖人：歷史照原樣發生，你可以趕到現場親眼目睹，也過著自己的一生。純 HTML/CSS/JS，手機瀏覽器直接開 `index.html` 即可（存檔在瀏覽器本機）。

- **年代**：開局可選射鵰篇（嘉定十五年，1222）、神鵰篇（嘉熙四年，1240）、倚天篇（至元元年，1335）。日期以南宋、元、明的真實年號顯示。
- **介面**：底部只有「江湖／人物／行囊」三個分頁；「人物」頁裡再分狀態、武功、人脈。標題列右上角的「設定」收納：參考（武學圖鑑、神兵譜、江湖記事、大事年表、玩法說明、美術出處）、歸隱、叛出師門、重新開始。
- **歷練（唯一的主行動）**：「江湖」頁只有一個主按鈕「歷練一個月」，其他手動行動（修煉、趕路、買賣、拜師、贈禮、閉關…）全部取消。按一次過約三十日，抽一件事（`js/adventure.js`）：拜師、師門差遣、傳功、晉升考核、市集、鐵匠舖、貨郎、藥舖、拜訪故人、提親、奇遇與戰鬥，全都在事件裡發生。已知的歷史大事日子近了，會有劇情「動身」帶你趕到現場。
- **三條路**：每個事件固定三個選項——**正派行動、反派行動、無視或拒絕**（身世開場、歷史現場、奇緣、節慶、傳功場景也一樣）。正派讓俠義上升、名門正派願意收你；反派常有立即的好處（銀兩、秘笈、寶物），代價是俠義下滑；無視則什麼也不沾。有些選項要擲 d20 檢定（骰點＋能力調整值對難度，難度隨等級慢慢提高），條件不足的選項會顯示原因並無法選取。
- **能力值與等級**：能力值只會因為升級配點、故事中的遭遇、以及裝備（兵刃、護甲、飾品、武功）而改變。事件與戰鬥給閱歷，升一級得三點屬性點數，彈出「等級提升！」視窗自行分配（可重置）。畫面頂部常駐等級經驗條與六項能力值，裝備加成以小字標示。
- **編年史**：36 件歷史大事（`js/chronicle.js`），其中 21 件有現場劇情。事前在「江湖風聞」或酒樓閒談中得知時間地點；人在現場就能親眼目睹並做自己的選擇，但改變不了歷史；錯過了只會聽到傳聞。年份大致依網路流傳的「金庸武俠小說大事年表」，原著沒寫的月份為本作自訂；所有敘述皆為改寫，非原著文字。
- **門派**：全真教、丐幫、少林寺、鐵掌幫（1240 年前）、武當派（1300 年後）、峨嵋派（1285 年後）、明教（1250 年後），依年代開放。旁觀者最高只能當到長老；升到長老後，可由掌門依序親傳鎮派絕學，每多學一門門檻再提高（全真同歸劍法；丐幫降龍十八掌、打狗棒法；少林易筋經；鐵掌幫鐵掌神功；武當神門十三劍，1357 年後再加太極拳、太極劍；峨嵋四象掌；明教聖火令武功、乾坤大挪移）。
- **出身**：不能選。開局隨機投胎，依年代從 13 種身分中抽一種（例如牛家村農家子、燕京王府的小廝、襄陽守軍之子、武當山下的樵戶），出生地、天資加成和開場身世各不相同。
- **個人生活**：隨機事件、奇緣小故事（`js/chains.js`）、情緣（好感夠了，對方會在路上與你重逢）、收徒。歸隱後可選一門武功傳給下一代，承接上一代或跳到後面的年代。
- **書中武功**：三部曲中的武功幾乎都已收錄（共 109 門），依原著的年代與地點做成奇遇：桃花島、九陰真經、白駝山、江南七怪、五絕、古墓派、李莫愁、絕情谷、金輪法王、楊過、崑崙、華山、崆峒、玄冥二老、成崑、青翼蝠王等。主角專屬的武功（黯然銷魂掌、玄鐵劍法、九陽神功）做成條件嚴苛的隱藏奇遇。武功頁有武學圖鑑，人物頁有神兵譜（神兵只能親眼見到，拿不到）。
- **同陣營一同學習**：師父在事件中示範武功時，陣營相同（正道）的主角可以一同學，不限於同一門派；陣營不同的只能旁觀，學不到。原著中師父教徒弟的場面都套用這個規則：松林降龍掌、客店逍遙遊、桃花島空明拳、懸崖全真內功、古墓玉女心經、涼亭玉簫劍法、華山打狗棒法、武當太極拳、光明頂乾坤大挪移，以及少林覺遠背九陽真經。
- **武功即裝備**：最多裝備五門武功，不分類別。攻擊類提供招式與攻擊力；內功決定氣血內力與內力屬性（裝備中最強的一門為主修）；身法提高閃避；輔助類不出招，只給戰鬥效果（例如移魂大法看破 +3、碧海潮生曲削弱對手攻擊、乾坤大挪移減傷並反震、一陽指與九陽神功每回合回血、暗器開戰先發、獅子吼開戰震暈）。每門裝備中的武功依類別加能力值（入門 +1、上乘 +2、絕學 +3），只有裝備中的武功會在實戰中長進，戰力也只算裝備中的武功（`js/data.js` 的 `ART_FX`）。
- **武功組合**：同時裝備可觸發加成，例如全真劍法＋玉女劍法＝玉女素心劍法（+30%）、降龍十八掌＋打狗棒法、太極拳＋太極劍、桃華落英掌＋彈指神通、左右互搏、同門相濟（三門同派）。
- **敵人戰力**：敵人戰力＝本身底子 × 0.8 ＋ 主角戰力 × 成長比例（上限 0.6）× 1.12，氣血與攻擊隨戰力加速成長（`js/game.js` 的 `FOE_K`）。以「看穿就克制」的打法模擬一生，整體勝率約七到九成。
- **戰鬥**：上方是雙方名字、戰力、氣血與裝備武功，中間顯示勝算。每回合先親手按「擲骰子（1~20）」看破（或「跳過投擲」以 10 計），加悟性、輔助武功與交手經驗，擲得越高越能看穿對手的攻擊牌；之後雙方各排六手，攻克破、破克守、守克攻。打不過可以「投降」。
